# 재택근무 규정

본 문서는 교육용 더미 데이터입니다.

## 운영 기준
재택근무는 주 2일까지 사용할 수 있습니다. 팀 필수 출근일(수요일)에는 재택근무를 사용할 수 없습니다.
신청은 전주 목요일까지 인사 포털에서 재택근무 신청서(양식 RW-201)로 제출합니다.

## 보안 수칙
재택근무 중 사내망 접속은 VPN 사용이 필수입니다.
개인 PC를 사용할 경우 보안 점검 프로그램을 설치하고 보안 서약서를 제출해야 합니다.
사내 자료는 승인 없이 개인 저장소나 외부 서비스에 올릴 수 없습니다.

## 근태
재택근무 시작과 종료 시 협업 메신저에 상태를 등록합니다. 근무 시간은 사무실 근무와 동일하게 적용됩니다.
